[CONTRIBUTING.md](../CONTRIBUTING.md).

| [collectors/README.md](collectors/README.md)   | Each collector, its category, its default state and its backing library, one page for each |

| [adding-a-collector.md](adding-a-collector.md) | The steps to write a new collector                                                         |
| [ocsf-validation.md](ocsf-validation.md)       | How to validate the gohai output and the vendor extension against the upstream OCSF schema |

The field names, the JSON Schema and the OCSF gap analysis are in
[`schemas/`](../schemas/README.md).
